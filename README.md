# dashboard-violencia-domestica-2023
Título: Panorama da Violência Doméstica contra as Mulheres em Minas Gerais (2023)
Dashboard interativo desenvolvido pelo Power BI com intuito de melhorar a prática com a plataforma. Tratamento e modelagem de dados provenientes do Portal de Dados Abertos do Estado de Minas Gerais (Controladoria-Geral do Estado e Polícia Civil de Minas Gerais).
